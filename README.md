# VibeCook

Планировщик ужинов. 152 рецепта. Полностью автономный HTML — работает сразу после открытия.

## Запуск локально
Открой `frontend/index.html` в браузере.

## Онлайн (GitHub Pages)
1. Залей репозиторий на GitHub.
2. Settings → Pages → Source: Deploy from a branch → `main` / `root` (или `frontend`).
3. Через минуту будет ссылка вида `https://salpadeine.github.io/VibeCook/` (или `/frontend/`).

Можно также просто открыть raw-файл или использовать любой статический хостинг.

## Возможности
- Составить неделю ужинов
- Клик по блюду → состав
- Список продуктов с указанием «для каких блюд»
- Выбор магазина
- Этап 2: полные рецепты + выгрузка .txt
- Сохранение «уже есть дома»

Вегетарианский фильтр убран.
