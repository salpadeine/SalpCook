# VibeCook

Планировщик ужинов. 152 рецепта. Полностью автономный.

## Онлайн
После заливки на GitHub и включения Pages сайт доступен по ссылке:

**https://salpadeine.github.io/VibeCook/**

(файл `index.html` лежит в корне репозитория)

## Локально
Просто открой `index.html` в браузере.

## Возможности
- Составить неделю ужинов из 152 рецептов
- Клик по блюду → состав
- Список продуктов с указанием «для каких блюд»
- Выбор магазина
- Этап 2: полные рецепты с шагами + выгрузка .txt
- Сохранение «уже есть дома» в браузере

## Структура
- `index.html` — само приложение (для GitHub Pages)
- `frontend/` — то же самое (резервная копия)
- `backend/` — опционально, если захочешь подключать реальные цены
