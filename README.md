# VibeCook

Планировщик ужинов с большой базой рецептов (150+).  
Составляешь неделю → получаешь список продуктов (с указанием для каких блюд) → выгружаешь список и пошаговые рецепты.

Фронтенд работает **только через бэкенд**.

## Структура
```
vibecook/
├── frontend/
│   └── index.html          # Веб-интерфейс
├── backend/
│   ├── app.py              # Flask API
│   ├── recipes.py          # 150+ ужинов
│   └── requirements.txt
├── README.md
└── .gitignore
```

## Как запустить

### 1. Бэкенд (обязательно)

Открой терминал и выполни:

```bash
cd backend
python -m venv venv
source venv/bin/activate          # Windows: venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Сервер запустится на `http://localhost:5000`.

### 2. Фронтенд

Просто открой файл `frontend/index.html` в браузере (двойной клик или перетащи в окно браузера).

> Если браузер блокирует запросы к localhost из-за CORS — бэкенд уже настроен с CORS, должно работать.

## Возможности
- **150+ полноценных ужинов** (без супов и завтраков)
- Клик по блюду → просмотр состава
- В списке продуктов указано «для каких блюд»
- Выбор магазина (Пятёрочка, Магнит, Лента, Перекрёсток)
- Два этапа: план → согласование → рецепты + выгрузка .txt
- Масштабирование порций
- Сохранение «уже есть дома» в браузере

## Реальные цены
В бэкенде стоит заглушка. Для подключения живых цен Пятёрочки:
```bash
pip install pyaterochka-api
```
и допиши логику в эндпоинте `/api/prices` (см. комментарии в `app.py`).
