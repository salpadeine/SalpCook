# SalpCook

Планировщик домашних ужинов на основе рецептов из каталогов «Еды» и «Шефмаркета».

## Онлайн

https://salpadeine.github.io/SalpCook/

## Каталог рецептов

В каталоге 171 рецепт ужина: 100 карточек из предыдущей партии и 71 дополнительная карточка, сверенные с конкретными рецептурными разделами публикаций Шефмаркета. Завтраки и супы не включены.

- У каждой карточки есть ссылка на страницу источника.
- 71 дополнительный рецепт собран по конкретным рецептурным разделам публикаций Шефмаркета: состав и последовательность действий сверены с оригиналом, шаги изложены своими словами.
- Для рецептов из статей-подборок в поле источника указано название конкретного блюда внутри публикации; для отдельных рецептов используются их самостоятельные страницы. Если автор не указал точное количество пасты или число порций, это отдельно помечено в карточке и не заменено выдуманным числом.
- Количества новых карточек перенесены из публикаций; если число порций в источнике не указано, базовое количество порций в приложении условное и не должно трактоваться как авторское.
- В карточке блюда отображаются ссылка на источник и ингредиенты; полные этапы приготовления находятся в подробном списке рецептов.

## Возможности

- План на 1–7 вечеров и настройка числа человек.
- Замена блюда без повторения уже выбранных блюд в пределах плана.
- Список продуктов, которые уже есть дома, с исключением их из покупок.
- Сводный список ингредиентов по категориям.
- Полные этапы приготовления и экспорт списка продуктов или рецептов.
- Сохранение плана и запасов в браузере.
- Мобильная прокрутка окна рецепта без прокрутки фона.

## Локальный запуск

Откройте `index.html` в браузере.
