# SalpCook

Планировщик домашних ужинов. 100+ обычных рецептов без полуфабрикатов.

## Онлайн
https://salpadeine.github.io/SalpCook/

## Особенности
- Много обычных домашних ужинов (котлеты из фарша, запечённая курица, паста, плов, рыба и т.д.)
- Никаких полуфабрикатов — всё готовится с нуля
- Подробные шаги
- Дни: «Первый день», «Второй день» и т.д.
- Цены примерные средние

## Локально
Открой `index.html` в браузере.


## Текущие возможности
- Замена блюда без повторов в других днях плана
- Список продуктов, которые уже есть дома, с исключением их из покупок
- Необязательный общий бюджет на меню и сравнение с примерной суммой покупок
- Сохранение плана и настроек в браузере
