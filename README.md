# SalpCook

Планировщик домашних ужинов на основе рецептов из каталогов «Еды» и «Шефмаркета».

## Онлайн

https://salpadeine.github.io/SalpCook/

## Каталог рецептов

В каталоге **200 проверенных рецептов ужинов**: 97 рецептов из «Еды» и 103 из «Шефмаркета». Завтраки и супы не включены.

- У каждой карточки есть ссылка на конкретный опубликованный источник.
- Названия, состав и последовательность приготовления сверены с источниками; инструкции изложены своими словами.
- Если источник не указывает число порций, приложение не придумывает его: в рецепте показывается предупреждение, а исходные количества остаются без пересчёта.
- Названия ингредиентов приводятся к единому виду для рецептов, домашних запасов и общего списка покупок. Словарь проверяется по всем 1 913 вхождениям ингредиентов в 200 рецептах; новые варианты добавляются как явные синонимы.
- Размерные уточнения, не меняющие продукт (например, средний/крупный картофель, размер помидора, огурца, моркови или лука), объединяются. Батат, черри, жёлтые и вяленые помидоры, консервированные томаты, разные виды фарша, сыров и масел остаются отдельными позициями.
- Альтернативы вроде «свежие или консервированные помидоры» не подменяются одним конкретным продуктом. Названия в каталоге сохраняют понятные префиксы: «Фарш…», «Сыр…», «Масло…» и т. п.

## Возможности

- План на 1–7 вечеров и настройка числа человек.
- Пересчёт количеств ингредиентов относительно базового числа порций рецепта; изменение числа человек обновляет уже построенный план и список покупок.
- Замена блюда без повторения уже выбранных блюд в пределах плана.
- Список продуктов, которые уже есть дома, с исключением их из покупок.
- Сводный список ингредиентов по категориям.
- Полные этапы приготовления и экспорт списка продуктов или рецептов.
- Сохранение плана и запасов в браузере.
- Мобильная прокрутка окна рецепта без прокрутки фона.

## Локальный запуск

Откройте `index.html` в браузере.
